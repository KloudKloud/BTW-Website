Linked Characters

💡 Just fill in the name and how they relate! The page will automatically show it as "Name — Type" for you. If you'd like to directly link another character (yours or someone else's) to a particular relationship, select the + button on the avatar above and find that character specifically! You can have as many relationships as you'd like~

e.g. Kloud belongs to you. Saphero belongs to you. When building Kloud's relationships, insert Saphero into the name field, and "Best Friend" in the type field. If Saphero has a page that exists, click the "+" button and select Saphero from your characters. Alternatively, if you have Kloud, and your best friend has Saphero, fill in the same info for the name and type field, but link his Saphero page through the "+" button :)
